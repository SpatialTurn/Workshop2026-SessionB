Hands-on spatial analysis with Python in Jupyter notebooks (Google Colab), using U.S. Census data as a case study: Python basics, getting ACS data through the Census API, cleaning it with pandas, and mapping it with GeoPandas.

This module was taught as part of the Purdue-NSF GIS Cybertraining for the Social Sciences Workshop, a two-day workshop held at Purdue University in 2026 (Day 1, Session B Python track). See the [Workshop 2026 page](https://spatialturn.github.io/workshop2026.html) for the full program.

It is part of [Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/), a set of training modules developed at Purdue University with support from the National Science Foundation.
