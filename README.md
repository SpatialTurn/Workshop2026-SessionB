# Geospatial Python

Source for the **Geospatial Python** module of the [Workshop 2026](https://spatialturn.github.io/workshop2026.html) materials, part of [Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/).
Published at <https://spatialturn.github.io/IGIC2026/>.

Hands-on spatial analysis with Python in Jupyter notebooks (Google Colab), using U.S. Census data as a case study: Python basics, getting ACS data through the Census API, cleaning it with pandas, and mapping it with GeoPandas.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/).
It is kept as it was taught at the workshop (Day 1, Session B Python track).

| Episode file | Title |
|---|---|
| `episodes/prelunch.md` | Python Notebook Introduction |
| `episodes/midlunch.md` | Acquiring and Exploration of Census Data |
| `episodes/postlunch.md` | Census Data Analysis with Python Notebook |

The Colab notebooks used in the episodes are in `episodes/`: `intro_python.ipynb`, `Question1_AnswerKey.ipynb`, `CensusDATA_Introduction.ipynb`, `Question2_AnswerKey.ipynb`. Learners need their own free [Census API key](https://api.census.gov/data/key_signup.html); no key is stored in this repo.
